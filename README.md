# Aplicaciones_web

Como iniciar los tres proyectos

# Ionic

En la carpeta Aplicaciones_web
en un cmd ejecutar lo siguiente
    npm install 
    ionic serve

# Flutter

En la carpeta Aplicaciones_web\proyecto_flutter
flutter pub get
flutter run -d windows

# Laravel

En la carpeta Aplicaciones_web\proyecto_laravel>
en un cmd ejecutar lo siguiente
    npm install
    npm install composer
    php artisan serve
